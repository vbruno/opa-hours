# OpaHours — backend

Este diretório contém a API, as migrações e os testes do OpaHours. Veja o [README principal](../README.md) para o estado atual, as funcionalidades e a configuração local.

Comandos disponíveis nesta pasta:

```bash
npm run dev
npm run build
npm run lint
npm run test
npm run test:integration
npm run db:migrate
```

Os testes de integração exigem um banco de teste configurado em `DATABASE_URL_TEST`.
